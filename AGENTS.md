# User interface approval

Preserve working behavior and UI that the user has approved, including appearance,
placement, animations, touch targets, and interaction feel. Ask the user before
changing any of these beyond the changes they explicitly request. An approval
for one UI change does not authorize adjacent redesigns or interaction changes.

Keep UI fixes narrowly scoped and retain the established styling and behavior
outside the requested change. When restoring an earlier UI, consult its existing
implementation and match it rather than introducing a new design.
